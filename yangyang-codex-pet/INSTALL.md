# 安装说明

## Windows

1. 下载或克隆本仓库。
2. 将 `yangyang` 文件夹复制到 `%USERPROFILE%\.codex\pets\`。
3. 确认最终文件路径为：

   ```text
   %USERPROFILE%\.codex\pets\yangyang\pet.json
   %USERPROFILE%\.codex\pets\yangyang\spritesheet.webp
   ```

4. 完全退出并重新打开 Codex。

## macOS / Linux

1. 下载或克隆本仓库。
2. 将 `yangyang` 文件夹复制到 `~/.codex/pets/`。
3. 确认最终文件路径为：

   ```text
   ~/.codex/pets/yangyang/pet.json
   ~/.codex/pets/yangyang/spritesheet.webp
   ```

4. 完全退出并重新打开 Codex。
