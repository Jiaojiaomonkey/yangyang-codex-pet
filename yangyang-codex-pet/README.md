# Yangyang Codex Pet

一个以玄鸟少女为灵感的 Codex 宠物：沉静、聪慧、可靠，并拥有青蓝色羽翼。

## 文件结构

```text
yangyang-codex-pet/
├── yangyang/
│   ├── pet.json          # 宠物配置
│   └── spritesheet.webp  # 精灵图（1536 × 2288）
├── README.md
├── INSTALL.md
└── .gitignore
```

## 安装

请参阅 [INSTALL.md](INSTALL.md)。安装后请保持 `pet.json` 与 `spritesheet.webp` 在同一个 `yangyang` 文件夹内。

## 使用与发布说明

- 图片文件约 2.8 MB，适合直接提交到 GitHub，无需 Git LFS。
- 上传前，请确认你拥有精灵图的发布与再分发权利。
- 本仓库暂未附带许可证；若计划允许他人复用，请在发布时添加与你意图一致的许可证。
